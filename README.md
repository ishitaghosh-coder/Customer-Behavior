# 🛒 Customer Behavior Analysis — E-Commerce Dataset

> **IBM SkillsBuild Data Analytics with AI Internship Project**  
> End-to-end data analysis and machine learning project on 25,000 e-commerce session records.

---

## 📌 Project Overview

This project analyzes customer behavior patterns from an e-commerce platform to:

- Understand what drives purchases vs. abandonment
- Identify the most effective marketing channels and product categories
- Segment customers into actionable groups using K-Means clustering
- Build and compare machine learning models to predict purchase likelihood

## 📊 Dataset Description : https://www.kaggle.com/datasets/kundanbedmutha/indian-e-commerce-customer-behavior-and-purchase

| Column | Description |
|---|---|
| `customer_id` | Unique customer identifier |
| `session_id` | Unique session identifier |
| `visit_date` | Date of session (DD-MM-YYYY) |
| `device_type` | 0=Desktop, 1=Mobile, 2=Tablet |
| `user_type` | 0=New, 1=Returning |
| `marketing_channel` | 0=Organic, 1=Email, 2=Social, 3=Direct, 4=Paid, 5=Referral |
| `product_category` | 0=Electronics … 7=Other |
| `unit_price` | Price per unit (₹) |
| `quantity` | Quantity in session |
| `discount_percent` | Discount applied (%) |
| `revenue` | Session revenue (₹) |
| `pages_viewed` | Pages browsed per session |
| `time_on_site_sec` | Session duration (seconds) |
| `added_to_cart` | 1=Added to cart |
| `purchased` | **Target** — 1=Purchase made |
| `cart_abandoned` | 1=Cart was abandoned |
| `rating` | Product rating (1–5) |
| `payment_method` | 0=COD … 5=Net Banking |
| `visit_season` | 0=Winter … 3=Autumn |
| `session_duration_bucket` | Very Short / Short / Long / Very Long |
| `location` | Location code |

## 📈 Key Findings

1. **~13% purchase rate** — large conversion optimization opportunity
2. **`added_to_cart` is the strongest predictor** of purchase
3. **Discounts >20%** meaningfully increase conversion rates
4. **Email and Referral** channels outperform Paid in purchase rate
5. **Electronics** is the highest revenue-generating category
6. **Returning users** generate higher average revenue per order
7. **Autumn/Winter** shows peak session volume (holiday demand)
8. **Cart abandonment rate ~38%** — prime target for recovery campaigns
